# やきとり ならべ

串に刺さった具を並べかえて、同じ具を4つそろえるパズルゲーム。そろった串は焼けて、カウンターのお客さんの注文に届きます。

- 串をタップ → 別の串をタップで、いちばん上の具（同じ具が続いていればまとめて）をうつす
- うつせるのは「からの串」か「いちばん上が同じ具の串」だけ
- 早く届けるほどチップが多い。待たせすぎて3人おこらせると閉店
- 困ったら「もどす」「＋串（1レベル1回）」「やりなおし」
- レベルが上がると具の種類が増え、待ってくれる時間が短くなり、同じ具を2本ぶん頼まれることも

## Webアプリとして

ビルド不要の静的サイト。スマホで開いて「ホーム画面に追加」すると全画面・オフラインで遊べます（PWA）。

公開先: `https://kouheim1979.github.io/launch-roulette/yakitori/`
（`main` に push すると `.github/workflows/atama-oshiri-pages.yml` が `gh-pages` に公開します）

## ローカルで動かす

```sh
cd yakitori
python3 -m http.server 8000
# http://localhost:8000 を開く
```
