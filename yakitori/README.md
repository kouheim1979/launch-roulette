# やきとり ならべ

焼き台に並んだ串を入れかえて、ひとつの焼き台に同じ串を3本そろえるパズルゲーム。そろった串は焼けて、カウンターのお客さんの注文に届きます。

- 串をタップ → 別の焼き台をタップ（ドラッグでもOK）で、空いている場所へうつす
- 焼き台の上の「つぎ」に、その焼き台が空になったら出てくる串が見える
- お客さんのうしろの「つぎ」が、次にその席に座る人の注文
- 早く届けるほどチップが多い。待たせすぎて3人おこらせると閉店
- 困ったら「まぜる（1レベル2回）」「＋焼き台（1回）」「やりなおし」
- レベルが上がると焼き台・串の種類・皿数が増える

## Webアプリとして

ビルド不要の静的サイト。スマホで開いて「ホーム画面に追加」すると全画面・オフラインで遊べます（PWA）。

公開先: `https://kouheim1979.github.io/launch-roulette/yakitori/`
（`main` に push すると `.github/workflows/atama-oshiri-pages.yml` が `gh-pages` に公開します）

## ローカルで動かす

```sh
cd yakitori
python3 -m http.server 8000
# http://localhost:8000 を開く
```
